fg asked on 2026-11-05 whether Orca is open enough to patch the way we patch VelaTerm, and said to keep the answer in mind for the future, not to raise it now. Orca is MIT, so a pinned fork is allowed. The cost is pace and size: 1,459 commits in a week against upstream VelaTerm's 1, and a repo of about 2.3 GB against 27 MB (read from GitHub that day). I haven't tried building it.

**Why:** if F-Co ever reconsiders hosting on Orca, a fork could replace part of the layer the evaluation describes.

**How to apply:** bring it up only if that question reopens, and re-read the numbers first. I'm grading VelaTerm's replacement when I do, so say so.
