## ⚠ A test that measured the spy, not the behaviour — my error, caught in review

`9dd9e64`'s commit message claimed "removing the await alone fails it." **False**, verified here:

```
await flushNow()  ->  void flushNow()     =>  Tests  8 passed (8)
```

**What went wrong:** the revert-proof removed **the call**, and the test caught that. The message was
then written as though the **await** had been removed. Two different mutations — one proved, the
other claimed. The test asserts `invocationCallOrder`, pure synchronous ordering, so `void flushNow()`
invokes at the identical point and every assertion still holds **while the promise dangles** — which
is precisely the unfixed bug.

`win/agent-ih8` caught it before it entered public history on PR #54 and added the case that measures
the real thing: hold the flush open with a deferred promise, assert `quit.confirm` has NOT fired,
resolve, assert it has. **9/9 with the await, that one case red without it.**

**The rule this reinforces** (see memory `feedback_verification_must_measure_what_it_asserts`):
a revert-proof only proves the mutation you actually made. **Mutate the exact thing the fix is**, not
a coarser thing nearby — removing a call is not the same as removing an await, and asserting on a spy
is not asserting on behaviour.

## Watching upstream — do NOT re-investigate or patch (fg's call, 2026-08-23)

**v0.1.102's "Not installed on this device" font warning is broken, and fg chose to wait for the
next upstream release rather than report or patch it.** Characterised fully; nothing left to learn.

`isFontAvailable` (`SettingsModal.tsx:367`) sets `ctx.font = '72px "X", monospace'` and compares the
measured width against the bare fallback. **WebKit's canvas cannot see user-installed fonts** — a
family in `~/Library/Fonts` silently falls back, as a font-fingerprinting defence. Measured in Safari
(same engine as the app's WKWebView), probe string `mmmmmmmmmmlliWWMO0@1` at 72px:

| family | mono stack | mono base | serif stack | serif base | verdict |
|---|---|---|---|---|---|
| FiraCode Nerd Font (**installed**) | 864.14 | 864.14 | 1010.29 | 1010.29 | not installed ❌ |
| "Definitely Not A Real Font" (control) | 864.14 | 864.14 | 1010.29 | 1010.29 | not installed ✓ |
| Menlo (system) | **866.95** | 864.14 | 866.95 | 1010.29 | installed ✓ |
| Monaco (system) | 864.14 | 864.14 | **864.14** | 1010.29 | installed ✓ |

An installed user font and a nonsense name produce **byte-identical numbers**, so **a negative verdict
carries no information**. Only macOS *system* fonts resolve. The warning is therefore wrong for
exactly the fonts people install deliberately — Nerd Fonts, JetBrains Mono, Cascadia.

- ⚠ **This is NOT our bug.** `isFontAvailable` is untouched by our branches
