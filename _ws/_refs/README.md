# _refs — outside sources & references

Everything from **outside this codebase** that the project draws on. Two kinds, one home:

- **Sources that inform & inspire** — foundational knowledge, curriculum, the domain/science the work
  rests on, and external material / examples / prior art worth living up to.
- **Technical references the build leans on** — API docs, library docs, specs, and the links you consult
  while building.

This is the *input* side — where the thinking and the technical facts come from. (Authored knowledge about
*this* code lives one level up, in `_ws/`.)
